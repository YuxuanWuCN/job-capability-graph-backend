# 岗智融析 · 上线作战计划（最终版）

> 版本 2026-11-22 · 目标：让职业规划大赛的学生**用手机扫码注册 → 上传简历 → 拿到岗位推荐与成长路径**
> 适用机器：阿里云 ECS **2核4G（华东2 上海）**，Ubuntu 22.04 LTS，100Mbps 按流量计费，IP + 8080 端口走 HTTP

## 0. 一页纸结论

**能上线，但必须按本文的顺序做，漏一步学生就用不了。**

| 结论 | 说明 |
|---|---|
| 系统主体可交付 | 后端 16 个路由模块、14 个迁移、前端 7 个页面；前端可构建（`tsc + vite` 通过），后端 AI 链路已适配 DeepSeek |
| 三个硬洞已补 | ① LLM 只认 OpenAI Responses API → 已加 chat 适配层（5 个单测通过）② 没有自助注册 → 已加邀请码注册（接口+页面+测试）③ 没有部署件 → 已补 `deploy/` 四件套 |
| 机器够用 | 2核4G 可支撑 20~30 人同时在线；必须按 §3 收紧参数 + 加 2G swap，简历解析 2 并发 |
| **产品天花板（必须知情）** | 正式岗位只有 **4 个岗位族**（33 项能力框架）。学生看到的"推荐岗位"只有这 4 类，不是 192 个新兴岗位——后者需要逐个审核发布，赛前来不及 |
| 安全边界 | 无域名无备案 → 只能 `http://IP:8080`，**密码明文传输**。仅限校内短期赛事使用，赛后关站 |
| 最关键的一步 | 必须跑 `bootstrap_capability_framework.py`，否则匹配报 404「当前没有正式图谱版本」，**学生什么都看不到** |

**最快路径（4 天）**：D-3 买机器+装环境 → D-2 部署+灌数据+冒烟 → D-1 内测 3~5 人 → D-day 正式开放。

## 1. 目标与验收标准

### 1.1 学生要能走完的 5 步

1. **注册**：扫码打开站点 → 输入邀请码 + 用户名 + 密码 → 自动登录
2. **上传简历**：PDF / DOCX，≤ 50MB
3. **等待解析**：Celery 后台调 DeepSeek 抽取能力画像（约 10~40 秒）
4. **确认画像**：人工核对/修订能力项 → 点「确认」
5. **看结果**：推荐岗位 + 匹配依据 + 能力缺口 + 成长路径

### 1.2 上线验收标准（14 条，逐条过，缺一不可）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 首页可访问 | 手机浏览器打开 `http://IP:8080` 能看到页面（不是白屏） |
| 2 | 静态资源 | 强刷后 JS/CSS 正常加载，控制台无 404 |
| 3 | 健康检查 | `/health/live` 返回 200；`/health/ready` 返回 200（四项依赖全 up） |
| 4 | 管理员登录 | `admin` 能登录，cookie 正常，刷新不掉登录 |
| 5 | 图谱已发布 | `/api/v1/graph` 返回节点数 > 0，`truncated=false` |
| 6 | 能力目录 | `/api/v1/catalog/capabilities` 返回 33 项 |
| 7 | 岗位目录 | `/api/v1/catalog/job-roles` 至少 4 条 |
| 8 | 注册开关 | 带对的邀请码能注册成功（201） |
| 9 | 注册拦截 | 带错邀请码返回 403 `INVITE_CODE_INVALID` |
| 10 | 上传简历 | 学生账号上传 PDF 成功，返回 `resume_id` |
| 11 | 解析完成 | 轮询 processing-run 到 `succeeded`，能看到能力项 |
| 12 | 确认画像 | 点确认后 `status=confirmed` |
| 13 | 生成推荐 | 点「开始匹配」返回岗位列表（非空） |
| 14 | 成长路径 | 点任一岗位能看到成长路径步骤 |

> 10~14 必须用**学生账号**测，不能只用 admin——匹配接口对 applicant 有额外校验。

## 3. 已定决策（含理由，别再改）

| 决策 | 取值 | 理由 |
|---|---|---|
| 机器 | 阿里云 ECS 2核4G（华东2 上海） | 这套栈常驻约 2.3G；2核2G 必 OOM，4G 是下限，靠 swap + 参数收紧撑住 |
| 部署形态 | Docker Compose | 仓库自带 compose，比裸装省 2 小时；无 Docker 也能装 |
| 访问方式 | `http://IP:8080` | 大陆未备案不能用 80/443 域名；8080 走 IP 不受备案限制 |
| `APP_ENV` | `local` | 代码里 `secure_cookie = (app_env == "internal")`，用 HTTP 必须 local，否则 cookie 不发送、登录直接坏 |
| LLM | DeepSeek `deepseek-chat` + chat 适配 | 系统原本走 OpenAI Responses API，DeepSeek 只有 chat/completions；改一处覆盖简历/成长/JD 三个环节 |
| 注册 | 邀请码开放注册 | 大赛现场扫码即用；邀请码留空即关闭注册 |
| 反向代理 | 宿主 nginx 托管前端 + 反代 `/api` | 同源，无 CORS、无跨域 cookie 问题 |

        ┌───────────────────────────▼─────────────────────────────┐

        │  worker (celery 4 并发)  ──┐                            │
        │  scheduler (celery beat)   │                            │
        │  postgres(pgvector) ◀──────┤                            │
        │  redis               ◀──────┤                            │

## 6. 部署 Runbook（从买完机器开始，逐条复制）

### 6.1 控制台三项（约 5 分钟）

1. 购买**阿里云 ECS 2核4G**（ecs.e，华东2 上海），镜像 **Ubuntu 22.04 LTS**，系统盘 60G ESSD Entry
2. 「安全组」→ 入方向添加规则：允许 `TCP:8080`（`22` 一般默认已开）
3. 记下**公网 IP**，并在控制台设置/重置 root 密码（或绑定密钥对）

> ⚠️ 不要开 80/443：大陆未备案会被拦，且 8080 足够。
> ⚠️ 下单前确认三件事：① 带宽选「按使用流量」100Mbps（并发强、只按实际出流量计费）② 必须分配**公网 IPv4**（没有公网 IP 学生根本访问不到）③ 登录凭证（密钥对/密码）当场存好，阿里云不保存明文。

### 6.2 装 Docker（服务器，约 3 分钟）

```bash
apt update && apt install -y curl
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
docker --version && docker compose version
free -h          # 确认约 4G 内存（可用 3.7G 左右）
```

### 6.2.1 加 2G Swap（4G 机器必做，5 分钟）

2核4G 常驻约 2.3G，剩 1.7G 余量。一旦有人上传超大 PDF 或 LLM 响应堆积，没有 swap 会被 OOM 直接干掉容器。

```bash
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
free -h          # 期望 Swap 一列有 2.0Gi
```

### 6.3 上传代码（本地执行）

```powershell
# 在项目根目录，排除体积大又用不到的东西（node_modules/.git/reports 都不传）
tar --exclude=node_modules --exclude=.git --exclude=dist --exclude=reports --exclude=backend/.venv -czf job-graph.tar.gz backend frontend compose.yaml deploy .env.example
scp job-graph.tar.gz root@<公网IP>:/root/
```

```bash
# 服务器
mkdir -p /opt/job-graph
tar -xzf /root/job-graph.tar.gz -C /opt/job-graph
cd /opt/job-graph && ls      # 应看到 backend/ frontend/ compose.yaml deploy/
```

> `backend/.dockerignore` 已排除 `.venv/`（本机虚拟环境有几百 MB），否则 `docker build` 会把整个虚拟环境上传一遍。

### 6.4 写生产 `.env`（服务器）

```bash
cd /opt/job-graph
cp deploy/.env.production .env
IP=<你的公网IP>
sed -i "s|http://IP:8080|http://$IP:8080|g" .env

# 生成真密钥
echo "SESSION_SECRET=$(openssl rand -hex 32)" >> /tmp/secrets.txt
echo "INVITE_CODE=$(openssl rand -hex 6)" >> /tmp/secrets.txt
cat /tmp/secrets.txt
vi .env
#   SESSION_SECRET  ← 粘贴 64 位 hex
#   REGISTRATION_INVITE_CODE ← 粘贴 12 位邀请码（学生要用它注册）
#   LLM_API_KEY     ← 粘贴 DeepSeek key（sk-...）
#   APP_BASE_URL / CORS_ORIGINS 已由 sed 改好，确认是 http://IP:8080
```

> `NEO4J_USERNAME` 不要写成 `NEO4J_USER`——拼错会导致启动时缺字段直接崩溃。

### 6.5 起基础设施 + 迁移 + 应用（一次起全）

```bash
cd /opt/job-graph
DC="docker compose -f compose.yaml -f deploy/compose.prod.yaml"

$DC up -d --build
$DC ps
# 期望：postgres/redis/neo4j/api/worker/scheduler 都是 running，migrate 是 exited(0)
$DC logs --tail=30 migrate
# 期望看到 alembic "Running upgrade ... -> head"
```

首次构建约 3~6 分钟（要下 Python 依赖）。

> 后面所有命令都复用这个 `$DC` 变量；关掉终端重连后需要先重新执行一次 `cd /opt/job-graph` 和 `DC="..."` 这两行。

### 6.6 建管理员 + 初始化图谱（**最关键，漏了学生看不到岗位**）

```bash
cd /opt/job-graph
DC="docker compose -f compose.yaml -f deploy/compose.prod.yaml"

$DC exec api uv run python scripts/create_user.py --username admin --display-name 管理员 --role admin
# 交互式输入密码两次（8~128 位）。第一个用户必须是 admin。

$DC exec api uv run python scripts/bootstrap_capability_framework.py --admin-username admin
# 期望打印 catalog_version_no / graph_version_no
```

> 这一步产出：33 项能力 + 4 个岗位族 + 一个已发布的正式图谱版本。跳过它，匹配会 404「当前没有正式图谱版本」。

可选（生成 3D 星图的候选数据，不影响主流程）：

```bash
$DC exec api uv run python scripts/import_emerging_job_definitions.py
```

### 6.7 LLM 连通性自检（必做）

```bash
$DC exec api uv run python scripts/llm_smoke_check.py
# 期望：[通过] returned_model=deepseek-chat ...
# 退出码 0=通，1=失败，2=没配
```

失败排查：`401` → key 错/没充值；`400` → 模型名或 URL 不对；`超时` → 大陆机器访问不了该地址。

### 6.8 前端构建 + nginx（本地构建，服务器托管）

```powershell
# 本地 frontend 目录
npm ci
$env:VITE_API_BASE_URL="http://<公网IP>:8080"
npm run build
scp -r dist root@<公网IP>:/var/www/job-graph/
```

```bash
# 服务器
apt update && apt install -y nginx
cp /opt/job-graph/deploy/nginx.conf /etc/nginx/sites-available/job-graph.conf
ln -sf /etc/nginx/sites-available/job-graph.conf /etc/nginx/sites-enabled/job-graph.conf
rm -f /etc/nginx/sites-enabled/default
chmod -R 755 /var/www/job-graph/dist
nginx -t && systemctl reload nginx
```

> 必须显式给 `VITE_API_BASE_URL`。为空时前端回落到 `http://127.0.0.1:8000`，学生手机上的请求会指向自己的手机，必然失败。

### 6.9 冒烟测试（一条命令跑 10 项）

```bash
cd /opt/job-graph
bash deploy/smoke_test.sh http://<公网IP>:8080 admin '<管理员密码>'
```

### 6.10 手机实测 + 开放注册

1. 手机浏览器（**4G 网络，不要连 WiFi**）打开 `http://<公网IP>:8080`
2. 点「使用邀请码注册」→ 填邀请码 → 注册 → 自动进 `/applicant`
3. 上传一份 PDF 简历 → 等解析 → 确认画像 → 看推荐

## 8. 风险与降级预案

| 风险 | 触发表现 | 处理 |
|---|---|---|
| **DeepSeek 欠费/限流** | 简历解析一直 `failed`，错误码 `LLM_RATE_LIMITED` / `LLM_UPSTREAM_ERROR` | 赛前充 100 元；现场点「重试」；仍不行则让学生手填能力项后确认（画像页支持修订） |
| 解析超时 | 任务卡在 `running` 超过 2 分钟 | `docker compose ... restart worker`；确认 LLM 响应时间 |
| Neo4j 挂了 | `/health/ready` 503，图谱页空白 | `docker compose ... restart neo4j`，等 40 秒 |
| 内存不足 | 容器被 OOM kill（`docker ps` 反复重启） | `docker compose ... logs api \| grep -i oom`；临时把 worker 降到 `-c 2` |
| 8080 被学校网拦 | 手机打不开 | 备用方案：手机热点；或临时用另一台机器做反代 |
| 邀请码泄露 / 乱注册 | 出现陌生账号 | 改 `.env` 里 `REGISTRATION_INVITE_CODE` → `docker compose ... up -d api`；或置空关闭注册 |
| 密码明文（HTTP） | — | 学生用一次性密码；赛后统一关站；一句话解释「校内测试环境」 |
| 数据丢失 | 误删/机器重装 | 赛前 `pg_dump`；卷 `postgres_data` / `neo4j_data` 在 Docker volume 里 |
